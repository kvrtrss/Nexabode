# Contributing to Nexabode

Thank you for your interest in contributing to Nexabode!

Nexabode is an open-source Windows desktop application for boarding house and rental management. Contributions, bug reports, documentation improvements, and constructive suggestions are welcome.

## Reporting Bugs

Before opening an issue, check whether a similar report already exists.

When reporting a bug, include:
- A clear description of the problem
- Steps to reproduce it
- Expected and actual behavior
- Relevant error messages, if available
- Your Windows version and Nexabode version

Do not include passwords, encryption keys, real tenant information, financial records, or other sensitive data in public issues.

## Suggesting Features

Explain the problem the feature would solve, how it could work, and any relevant use cases. Feature suggestions are open for discussion and are not guaranteed to be implemented.

## Submitting Code Changes

1. Fork the repository and create a branch for your change.
2. Keep changes focused and explain their purpose.
3. Build the solution in Release configuration.
4. Run available tests and manually verify relevant behavior.
5. Submit a pull request describing the changes and tests performed.

Please do not include generated build files, personal data, credentials, encryption keys, or unrelated changes.

## Security Issues

Please do not publish exploitable security vulnerabilities or sensitive information in public issues. Follow the instructions in [SECURITY.md](SECURITY.md).

## Code of Conduct

All contributors are expected to communicate respectfully and follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## License

By submitting a contribution, you agree that your contribution may be distributed under the project's MIT License. Only submit work that you created or have permission to contribute.

## Maintainer Review

Contributions may be reviewed, requested for changes, accepted, or declined at the maintainer's discretion. Please be patient while awaiting a response.
